# Stress Level Prediction Using Machine Learning

## Project Overview
This project predicts stress levels using machine learning techniques based on technology usage, lifestyle habits, and mental health indicators.

## Dataset
The dataset contains information such as:
- Age
- Gender
- Technology Usage Hours
- Social Media Usage
- Gaming Hours
- Screen Time
- Sleep Hours
- Physical Activity
- Mental Health Status
- Support Systems
- Work Environment
- Stress Level

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- CatBoost
- Matplotlib
- Jupyter Notebook
