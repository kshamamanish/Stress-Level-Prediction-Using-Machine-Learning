# Stress Level Prediction Using Machine Learning

## Project Overview

This project predicts stress levels using machine learning techniques based on technology usage, lifestyle habits, and mental health indicators.

The project compares multiple machine learning algorithms to classify stress levels and evaluates their performance using standard classification metrics.

---

## Objectives

- Predict stress levels using machine learning models.
- Compare the performance of different classification algorithms.
- Identify the most important factors influencing stress levels.
- Demonstrate end-to-end data analysis and machine learning workflow.

---

## Dataset

The dataset includes the following features:

- Age
- Gender
- Technology Usage Hours
- Social Media Usage
- Gaming Hours
- Screen Time
- Sleep Hours
- Physical Activity
- Mental Health Status
- Support Systems
- Work Environment
- Stress Level (Target Variable)
